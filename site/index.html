    Why developers use ModelarDB

    Compression

    Reduce storage costs by  up to 99% by compressing petabytes of time series data efficiently and effectively. The data can be compressed losslessly or within a user-defined error bound.

    Python Library

    Read and write compressed time-series data directly in Python. The data can be stored in ModelarDB or in files, and analyzed standard Python tools such as Jupyter, Pandas, and PyTorch.

    Full Power of SQL

    Do analytics with full power of SQL queries transparently executed directly on compressed dasta.

    Flexible Deployment

    Data is collected on the edge (e.g., wind turbines), compressed, and continuously transferred to the cloud from where all data can be queried by the client.
